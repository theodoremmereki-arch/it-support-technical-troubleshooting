# IT Support & Technical Troubleshooting

## Project Overview

This portfolio documents practical IT support and technical troubleshooting experience gained while working as an IT Technician during an industrial attachment at the Department of Wildlife and National Parks (DWNP), Botswana.

My responsibilities included supporting end users, troubleshooting network connectivity, administering user accounts, configuring workstations and assisting with IT infrastructure maintenance.

This repository is a professional case-study portfolio rather than a software application.

## Selected Troubleshooting Case Studies

### Case Study 1: Network Connectivity Problem

**Problem:** A workstation experienced unreliable network connectivity.

**Approach:**
- Inspected physical network connections
- Identified an Ethernet connection problem
- Used an alternative network connection as a temporary workaround

**Outcome:** Restored temporary connectivity while addressing the underlying cabling issue.

### Case Study 2: Domain Connectivity

**Problem:** A workstation required reconnection to the organizational domain.

**Approach:**
- Checked network configuration
- Verified connectivity
- Reconnected the workstation to the domain

**Outcome:** Restored domain connectivity.

### Case Study 3: Internal Application Availability

**Problem:** Users experienced difficulty accessing an internal application.

**Approach:**
- Investigated server connectivity
- Used Command Prompt to test communication
- Assisted with the server restart procedure

**Outcome:** Application availability was restored.

### Case Study 4: Remote Office IT Support

**Problem:** Workstations at regional offices required technical attention.

**Approach:**
- Assisted with on-site network troubleshooting
- Checked workstation configurations
- Supported domain reconnection and IP configuration

**Outcome:** Helped restore workstation connectivity and functionality.
